# Overview

This project is a simple Python program that displays greeting messages in the terminal. It prints “Hello World!” followed by two additional messages.

I created this software to improve my programming skills and build a strong foundation in software engineering. I want to learn how to write, run, and manage code as I prepare to develop more advanced software projects.

[Software Demo Video](https://youtu.be/P7Z-7IaMUEA?si=P5YkrJD0mRhOOomt)

# Development Environment

I used Visual Studio Code to write and edit my code, Python to run the program, Git Bash for version control, and GitHub to publish my source code.

The programming language is Python 3.13.13. The program uses the built-in `print()` function to display text in the terminal.
